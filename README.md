
# Spotify HUD

<img src="https://github.com/user-attachments/assets/5f076bed-184e-4ec9-8890-2546f0c1544f" width="600"/>

Displays your currently playing Spotify song in a clean, customizable HUD.

## Features

- Shows current song
- Displays artist and album cover
- Customizable HUD
- Client-side only

## Compatibility

- Minecraft 1.21.X 
- Fabric Loader
